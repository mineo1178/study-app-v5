# v1.89.8 ガントと計画管理の分離

通常画面をガントに統一し、「計画を更新」から独立した取込画面へ進む構成にした。保存方式・Rules・学習実績と比較計算は変更しない。

- ガントは初期全展開。名称・進捗・終了日・日付軸に整理し、終了日は採用済み予定を優先、なければ提案、未設定は「—」。履歴目標は課題詳細へ移動。
- 通常画面には対象回・資料revision・仮／確定状態・短い容量注意と表示操作だけを表示。カードと週間表示の独立タブを外し、既存の学習開始・集計は管理内の補助表示で保持。
- 取込はSTEP 1 ファイル選択、STEP 2 差分確認、STEP 3 参照保存。実際のfile inputをボタンから開き、ファイル名を表示。未選択時に保存ボタンは表示しない。
- 現在／選択した資料revisionとアプリrevision、計画ID、対象・工程案・対応・不一致・容量状態と差分を表示。同一内容は再保存不要、旧版・不正形式・別アカウントは拒否。異なる計画IDをrevisionの数字だけで比較しない。
- 保存完了を待って成功表示し、「ガントを見る」で戻る。参照保存は採用を伴わない。従来形式の採用、正式教材照合、対応確認、出力は「詳細設定・エクスポート」へ移動。
- 課題詳細の手動日・提案日・目標日・工程・履歴・赤紫の分析、既存タイマーと旧計画編集を維持。
