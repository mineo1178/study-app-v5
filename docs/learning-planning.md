# 学習計画・追加練習・目標時間（v1.89.0）

## 保存と互換性

既存 `families/{familyId}/tasks/{taskId}` を共通の正本とする。タスクをガント用に複製しない。
任意の `planning` フィールド（schemaVersion 1）へ以下を保存する。

- revision、順番、手動の終了予定日、締切
- 範囲ID・名称・固定作業量・予定分数・予定日
- 範囲終了・採点・必要な直しの完了と、独立した実績日
- 固定目標基準（ID・作成日・目標日・日別作業量・推定根拠）と旧基準履歴（最大50件）

旧タスクに `planning` がなくても読める。途中状態から率を推測しない。
計画はtransactionで既存revisionと照合し、競合は上書きせず再読込を促す。自動再送しない。
範囲の完了はタスクのstatus・学習履歴・報酬を変更しない。全体完了は明示操作とし、全範囲の採点・直し、タイマー保存を必要とする。

学習可能時間は `studyPlanning/{認証UID}` に保存する。未設定日は目標日の算出から除外する。
教材は `studyMaterials/{materialId}` から既存taskIdへ紐付け、`studyMaterialFiles/{SHA256}` で同一PDFの別教材への重複登録を防ぐ。問題・解答は同一教材の関連資料とする。
追加教材の新規taskIdは内容ハッシュに基づく安定ID。transactionによる再試行でも二重作成しない。既存タスクへの紐付けは回・教科を照合して本人が選ぶ。

## 計算

範囲の固定作業量は、同じタスク内で同一単位を使用する。進捗は「範囲終了・採点・必要な直し」のすべてが完了した範囲の作業量 / 全範囲の作業量。親は各タスクの固定予定分数で加重平均する。率または重み不明を含む親は未確認とする。既存の全体完了statusは100%として表示する。

赤実線は同じ実績進捗から保存済み日別配置の今日までの作業割合を引く。紫破線は固定目標基準の今日までの割合を引く。左が遅れ、右が先行。差の単位はポイントであり、日数・予測終了日の遅れに変換しない。均等配分は使用しない。未測定・基準未設定は線の計算から除外する。

手動の終了予定日は自由に変更できる。保存済み日別配置は別の比較基準なので日付を変更しても自動で移動しない。必要な範囲の日付をタップまたは日付入力で調整して保存する。

目標基準は同一taskIdの採点済み・同じ作業量の履歴を優先し、なければ同教科・同教材名・同カテゴリを比較する。初回平均＋初回件数あたりの直し合計時間を推定時間とする。確認待ち・操作確認を除外し、採点済み0点は有効。課題ごとの最初の初回から最後の直しまでの暦日差の平均（切上げ）を直し日数とし、日別割当の下限へ反映する。日付が不明なら未確認・仮目標と明示する。他タスクの配置時間を可能時間から差し引く。未配置課題の時間は未確定として含めない。

履歴や直し実績が不足すれば仮目標。手動補正と対象件数・採用条件・初回/直し時間を表示する。将来366日までに必要時間を確保できなければ目標を作らない。締切超過を警告する。目標は作成時点で固定し、再計画時のみ新IDへ改訂して旧基準を保持する。固定後は比較の分母となる範囲作業量・予定分数を変更しない。

## 追加練習

既存attemptsのmodeへ `practice` を追加する。通常の `daily` / `retry` の進捗計算は維持する。追加練習の保存ではprogressを更新せず、Rulesでもpracticeによるprogress更新を拒否する。履歴には追加練習と明示する。

最大5問。期限とは独立し、有効な次回計画の実在ID・版を優先する。一般問題への補完も可能。前日以前の最近50回答から未出題・誤答・回数を考慮し、同順位はJSTの日付で回転する。同日の選択を認証スコープ別の端末キャッシュへ固定する。問題の公開状態・版や有効計画が変わった場合は選び直す。開始済みdraftは従来どおり復元する。端末キャッシュ不可は警告する。

## 目標時間と通知

既存の学習・計算タイマーを利用し、目標秒数と実測秒数を別々に記録する。プリセット3/5/7/10/15分と分・秒入力を用意する。0秒の途中入力は許容し、0秒のまま開始しない。

一般学習は採点済み・同作業量・同モードの履歴を照合する。旧記録に条件がなければ仮設定。計算は直近30学習日の保存済み7問を同じtaskId優先で照合し、初回/直しはtaskId・JST日ごとに判別する。既存の一日全体のattemptNo/attemptTypeは書き換えない。手動設定と履歴平均を区別し、平均を再採用できる。

通知は継続・一時停止・終了へ接続する。Web Audioは利用者の操作で有効化する。スリープ中の音は保証しない。復帰時に壁時計で表示を補正する。計算の保存済みrunning途中記録はmeasuredAtから復帰までを補正し、再読込後は一時停止して利用者の再開操作を待つ。停止中・採点中の時間は増やさない。旧途中記録にmeasuredAtがなければ既存の保存秒数を保つ。一般学習の無操作・長時間バックグラウンド確認、活動Pの二重計上防止は既存経路を維持する。

## 公開とロールバック

本番一括更新・migration・個人資料の公開は行わない。教材JSONは端末から明示的に読み込み、必須/補強/発展の要確認状態は確定するまで登録できない。ローカルパスをリンクとして配信しない。認証付きPDF配信方式は未設定。

本番公開には別途承認が必要。新Rulesの反映とアプリ更新をセットで扱う。旧UIへのロールバックは基準SHA `5a18396c633bec05661a88c7e7cb7d293bc84ec1` を再デプロイし、追加フィールド・履歴・教材タスクを削除しない。旧UIは追加練習の履歴表示を区別できないため、公開済みの場合は新しい読み取り互換性を残す修正版を優先する。

実利用者の資料対応・必須区分・学習可能時間・端末スリープ音声は本番で未確認。テストの架空教材・日付・進捗を実データへ流用しない。
