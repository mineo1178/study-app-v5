# 正式予定案のアプリ照合（v1.89.2）

元資料：`study-schedule-plan.v1.json`（1.0.0）。アプリの保存形式：従来の`learning-schedule/1`。前者のproposalTaskIdは実taskIdではありません。個人PDF・schedule-evidence.private.jsonはアプリや公開Gitに入れません。

## 操作

1. 「保護者：ローカル計画JSONの取込・更新」で正式予定JSONを選択します。アプリ形式へ変換済みの正式提案候補、またはアプリの照合・進捗エクスポートも選べます。
2. 教材・試験予定・授業日・推奨工程・未確認事項を確認します。教師指定提出日nullは未確認で、家庭推奨日とは別です。本人の受験予定も未確認ならそのまま表示します。指導者用資料は教材一覧のみで課題化しません。
3. 各候補に回・教科で絞った既存タスクを表示します。完全なmaterialId・カテゴリ・範囲一致以外は自動確定しません。カテゴリ・教材・対象範囲を照合した根拠を入力し、対応確認と採用対象の両方を明示選択します。同じtaskIdへの複数提案は範囲重複を保証できないため拒否します。
4. 実施日、家庭推奨終了日の採用は別操作です。初期状態では新しい推奨日を既存終了予定日へ反映しません。条件付き候補・未照合分は保留です。0件のときは照合待ちの参照案だけを保存できます。除外・保留でも従来タスク・採用済み予定は自動削除しません。
5. 「照合結果を取込プレビューへ」で最新の採用計画を維持した変換結果を確認し、現在のアカウントへの取込を確認して保存します。保存直前に基点revisionをtransactionで再確認するため、他端末で計画が変わった場合は再プレビューが必要です。
6. 採用した実施日の候補は「今日やること」とガントに表示します。作業量・時間が不明なら未確認のままで、ページ数を問題数や作業量へ勝手に換算しません。提案の直し工程は条件付きであり、直した実績を生成しません。学習時間は従来のタスク・タイマーから記録します。

## 保存・改訂

`proposalImport.source`に検証済みの公開用予定構造（個人根拠やPDFを除く）、`records`にproposalTaskId/実taskId/照合根拠/対象タスクのidentity/採用選択を保持します。元のplanId+revision+proposalTaskIdで対応を追跡し、アプリの採用・照合revisionは別に単調増加します。完全に同じ取込は既存版を返し、重複タスクや重複予定を作りません。同じ元revisionの内容変更や古い元revisionは拒否します。旧版は変更不能な既存の保存先で保持します。Rules・認証・外部サービスは変更しません。

新しい元revisionでは手動終了日・固定目標の変更採用チェックをリセットします。旧目標は自動変更しません。元の教師指定日、家庭推奨日、採用した終了日、履歴目標日、試験日、授業日は独立した情報です。v1.89.1の仮締切・仮容量を正式資料で確認した値として扱いません。

## 履歴と目標

同一taskIdを優先し、同じ確認済み作業量、採点済み、操作確認用でない有効履歴のみ集計します。異なる教材・範囲を無条件に平均しません。初回時間・直し件数/時間・日付が分かる場合の間隔を別表示します。元JSONの履歴推定nullはゼロへ変えません。作業量・履歴・容量がそろい、保護者が明示選択したときだけ、新規固定目標を既存計算で作成します。既存目標の上書きは行わず、履歴参照・算出根拠・日別基準量を固定保存します。容量未確認の目標は仮目標と表示します。他の採用課題の時間が不明で配分を確認できない場合は拒否します。

赤・紫は従来の進捗差計算を維持します。数量不明の提案や未採用候補を架空の進捗率・遅れへ換算しません。既存completedの100%や既存実績も維持します。

## ローカルへの出力

「照合・進捗・採用予定を保存」は`schedule-feedback/1`を出力します。実taskId、回/教科/カテゴリ/教材識別、状態、確認可能な範囲進捗、採用予定/基準、同条件の時間集計、proposal対応、未確認・保留理由を含みます。成績・回答本文・認証トークン・UID・個人PDF/private evidenceは含めません。このJSON自体も私的な再計画用資料です。

ローカルでproposalImport.sourceを更新し、元revisionを増やして再選択するか、新しい正式予定JSONを生成して再照合します。既存採用計画はアプリの最新版を使い、書き戻したcurrentPlanを盲目的に上書きしません。Windowsローカルファイルの自動監視は行いません。
