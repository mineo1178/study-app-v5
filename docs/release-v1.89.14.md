# v1.89.14 WBS直接編集の簡素化

- 既存WbsCell・planning.revision・transactionを再利用。日付セルは手動値を優先し、未入力時に予定/提案を候補表示する。候補表示やキャンセルだけでは保存しない。
- 進捗だけの保存では提案日を手動予定へ昇格させない。日付の未設定へ戻す操作を追加し、手動解除後は元の予定/提案を保持する。手動0〜100%・自動へ解除・競合時入力保持を維持する。
- 列は名称・開始日・終了予定日・管理進捗・完了/全件・残件数・遅れ・日付軸へ整理。管理進捗は1値（手動/実績/未測定）とし、taskIdを重複集計しない。同名の教材/課題を繰り返さない。
- 遅れは日数・短い赤紫ポイント差・比較不可へ集約。手動しかない比較は中立色の「手動参考差」。2つの日付から日別進捗を推測せず、既存の採用済み基準を使用する。
- 詳細は日付・進捗・残件数・遅れと「学習を開く」を先に表示。根拠/赤紫分析・工程/実績・固定目標/手動履歴・ローカル提案・旧編集を折りたたむ。PC一覧を縮めず、スマホ幅内へ詳細を表示する。
- DailyView・タイマー・採点/直し・実績/履歴・報酬/復習・正式教材照合・固定目標・計画revision・Rules・ローカルJSONは変更しない。手動100%でもtask.statusや報酬を変更しない。
