# v1.89.28 課題の保護とプリント教材対応

## 課題保護

- 個別削除2か所・回単位削除を、元documentのバックアップと監査を同一transactionで保存する論理削除へ変更。バックアップ失敗・実行中/未保存タイマー・対象変更時は削除しない。回単位削除は件数の再入力が必要。最大100課題、バックアップ700KBを超える操作は分割が必要。
- バックアップはfamily内の `taskArchives/{uid}/entries/{operationId}` にアカウント別・追記専用で保存。認証uid・サーバー時刻・操作種別・対象ID・件数・元documentを保持する。通常の課題削除では消せない。
- スケジュールの「削除した課題を復元」から、同じアカウントの別端末でも復元できる。元taskIdのdocumentから非表示印だけを除き、復元監査を追記。履歴・採点・進捗・固定目標・報酬・教材/計画参照を再作成しない。
- Rulesは物理削除、バックアップと対にならない論理削除、監査なし復元を拒否。既存task更新にはserver-readの `_writeVersion` を進めるtransactionが必要。古いクライアントの全件置換・直接上書きは拒否されるため、v1.89.28へ再読込が必要。
- 新規課題作成は既存IDがあれば全件停止。通常の項目更新は対象フィールドの変更前値も照合し、古い未同期データに照合情報がない場合は保全して自動再送しない。タイマー・計画・教材の既存競合判定は維持し、保存版と削除状態のチェックだけ追加。
- 取得件数が少ないことを理由にサーバー課題を削除する同期、全件リセット、計画取込での課題削除は対象コード内に存在しない。2026-11-14の消失原因は未特定のまま。

## 教材対応

- 既存の候補生成・アカウント別クラウド保存・差分JSON出力を再利用。スケジュール上部にプリント一覧を追加し、回・教科・元登録名・対応状態から候補選択、確定保存、変更、解除が可能。
- 候補は確認済み教材メタデータに限定。旧A/B/Sと正式区分の自動対応はしない。同じ回・教科・種別による候補で、taskIdとの一意対応根拠ではない旨を表示。初期選択なし。
- 確定直後にガントの表示名へ反映。旧登録名・taskId・並び順・期限警告/凡例は保持。アプリの確定とローカル教材台帳は未同期であり、差分JSONを出力して照合する。
- 実アカウントの教材対応は今回確定しない。個人情報・実taskId対応表・PDF・非公開パスをバンドルやGitへ追加しない。

## 検証と制約

関連unit35件、Firestore emulator30件（正常保存・同時更新・削除/バックアップ/監査/復元・46課題一括・失敗時原子性・旧更新拒否・別アカウント分離）、詳細/一覧/復元UIの1440px・375pxブラウザ確認。typecheck/build、変更範囲lint（既存Appの指摘は増加なし）、diff-checkを実施。

本番課題での削除・教材確定テストは行わない。公開前後の読取スナップショットで91課題・復旧32件・既存59件・保護領域を照合する。Rulesは認可を厳格化するが、Admin SDK・管理者の直接操作・コンソール削除は対象外。既に起きた消失の原因特定や欠損値の推測補完を行うものではない。バックアップの自動期限削除は設けず保持する。復元は削除したアカウントに限定する。
