# v1.89.9 学習トップの復元と進捗差

学習タブの初期表示を既存DailyViewへ戻した。「学習スケジュール」でガントへ進み、「学習に戻る」で復帰する。再読込・再ログイン・学習タブ再選択もDailyViewを初期表示する。

- ガント表示中はDailyViewを非表示で保持し、選択中の回、子コンポーネントのフィルタやタスク下書きを失わない。既存の登録・状態・タイマー・履歴・削除処理は再利用する。
- 復元したトップの見出しを読めるよう、既存背景に対する文字色だけ補正した。
- ガントの進捗セルへ赤（採用済み手動計画）・紫（保存済み固定目標）のポイント差を追加。既存displayDifferenceの値を使い、正は先行・負は遅れ・ゼロは予定どおり。進捗・比較基準が不明なら比較不可。
- 未採用提案を正式な遅れ判定へ使わない。親行は全課題の実績・正の予定分数・比較基準がそろう場合だけ、従来と同じ予定分数の重みで集計する。
- 日付列幅・階層・色・詳細パネル・計画取込は維持。遅れ表示は2段の進捗セル内に置き、日付列を狭めない。
