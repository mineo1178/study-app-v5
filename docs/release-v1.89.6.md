# v1.89.6 未採用の工程提案

既存の正式予定1.0.0のplanningPolicyに保存した、実タスクごとの工程案をガントで参照できるようにした。GUI構成、採用済み予定、進捗計算、保存transaction、Firestore Rulesは維持する。

- 未採用工程は灰色破線、終了日は「提案」として表示する。青い採用済み予定・緑の実績へは変換しない。
- taskIdに加え回・教科・カテゴリ・教材名・materialIdが一致した参照だけを表示。未知ID、重複・不正形式、完了済み課題からは提案棒を作らない。
- 詳細で初回演習・採点、条件付きの直し予約、最終確認の日付と仮分数を表示。容量超過の案には警告を出す。
- 正式JSONの参照取込と、教材対応確認・予定採用は従来どおり別操作。未確認の作業量を範囲や固定目標へ自動変換しない。
