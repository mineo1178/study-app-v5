# v1.89.5 学習スケジュール

学習画面の初期表示を、全階層を展開した横方向ガントへ戻した。今日のカード・週間予定・保護者向け詳細は別タブと補助表示で維持する。

- 回→教科→教材→課題、進捗、終了予定、目標終了を同じ行に整列。全展開・全折りたたみに対応。
- 標準課題行は約40px。名称列と日付見出しを固定し、表の内部だけで縦横スクロールする。長い教材名は切り捨てず折り返す。
- 今日から7日／14日、週末見出し、今日の縦線。登録済みの日だけ青の予定棒と緑の実績棒を表示し、予定のない間隔を連結しない。棒の長さは進捗率ではない。
- 課題を選ぶと横の詳細パネルへ。スマホは右側のドロワー。対象範囲・予定・実績、既存タイマー、旧計画編集を利用できる。
- 赤実線・紫破線は選択課題の詳細に限定。従来の計算、未測定判定、完了100%、手動設定・参考日・固定目標の区別を維持する。
- JSON取込・教材照合・revision管理・エクスポート、既存の保存transactionと権限境界は変更しない。未確認提案の採用や本番データの一括更新は行わない。
