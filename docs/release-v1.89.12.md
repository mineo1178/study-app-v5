# v1.89.12 進捗診断・試験前の工程計画

- WBS上部に完了・残り・期限超過・比較可能な遅れ・比較不可を表示。期限設定数と比較可能数も明記し、比較基準のない0件を順調と誤認させない。
- 選択課題の詳細に実績・管理用手動・今日までの採用済み計画・固定目標を分けて表示。赤紫のポイント数値と従来の個別グラフを維持し、不足する範囲/実績/日別基準を列挙する。
- 手動しかない場合は、採用済み基準があれば「手動進捗による参考比較」と表示する。正式な赤紫指標・遅れ件数には含めない。未採用の提案を正式な比較基準にしない。
- 進捗エクスポートに残量、既知の実績日時、不足情報を追加。残時間の根拠が不足する場合はnullとし、管理用手動値や仮の工程分数を実績へ変換しない。
- 確認済み土曜試験から水曜の初回/採点・金曜の直し/最終確認を導く純粋な生成処理を追加。授業後の取組可能日、既存予約、完了除外、条件付き直し、工程別容量を扱う。全課題案は超過を隠さず、優先候補案は収まらない課題を保留として保持する。
- 計画・個人根拠・進捗スナップショットは私的フォルダに保存し、旧revisionを保持する。資料revisionとアプリrevisionを区別し、正式採用は利用者の明示操作とする。
- DailyView・タイマー・実績保存・status・報酬・復習・固定目標・Rulesは変更しない。既知の削除時の詳細表示競合は別課題のまま。
