# v1.89.10 ガント順序・件数・比較理由

- 回番号を数値降順へ変更し、教科を算数→国語→理科→社会へ固定。教材・課題の既存順を維持する。全角数字も数値として扱う。
- 親階層に「完了／全課題数」を表示し、取り組み中・未着手も件数の補足に集計。範囲完了と課題全体完了を混同せず、task.statusで件数を数える。
- 件数ベースの完了率を作業量進捗へ流用しない。全課題完了でも親の重みが不足すれば作業量は未測定。重みが成立する場合の既存加重集計は維持する。
- 赤・紫の数値と詳細グラフの計算は従来どおり。比較不可の理由を、範囲・作業量、採点・必要な直しの実績、採用済み日別予定、固定目標の日別基準に分けて詳細へ表示する。
- 初期全展開、全開閉、終了日の予定／提案／不明、色、期間外への導線、DailyViewと既存タイマーを維持する。未採用提案から正式な遅れを作らない。
