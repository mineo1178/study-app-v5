# v1.89.3 ガント表示と照合補助

- 根本原因：旧ガントの青/緑要素は空白文字でも常に描画され、背景色が予定/実績のない日にも付いていた。主画面は取込計画itemsだけを対象にし、既存タスクの手動設定・範囲・固定目標や学習履歴だけの場合の表示を十分に扱っていなかった。未設定のデータを数値で埋める処理は追加しない。
- 主画面でも既存タスクを表示し、completed100%、未着手、進捗未測定、計画未登録を区別。範囲の測定記録がないときは0%や進捗差を生成しない。終了予定は採用設定を優先し、旧手動日との相違・未採用参考日を別表示。固定目標を読み、未採用の履歴候補と算出条件不足を区別する。
- 青は保存された予定/明示採用した実施日だけ、緑は保存された範囲実績/日時が確かな有効学習履歴だけ。時間履歴から範囲進捗を推測しない。両画面で空日の着色を除去し、予定/実績の意味を文字・titleで表示。赤/紫は同じ測定進捗と既存の日別差計算を使い、比較可能な線だけ描く。今日列・固定見出し・固定課題列を維持。
- 上部に正式提案/対応確認/採用/保留/revisionを表示し、照合画面への入口を追加。正式案未取込や採用待ちを明示。仮計画と正式提案を区別。教材は初期折りたたみと一括開閉でコンパクトにし、回→教科→教材→課題を維持。
- 照合はA（materialId・確認済み範囲等が一意一致）、B（関連候補だが差異/未確認あり）、C（対応根拠を持つ候補なし）を表示。Aを先にし、Bの表記差・カテゴリ差・ID/範囲不足を具体表示。候補と根拠を先行入力してもverified/selectedはfalse。保護者の対応確認と採用確認は別操作で維持。
