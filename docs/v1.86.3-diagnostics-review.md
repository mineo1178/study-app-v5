## 4. START／STOPの記録

`BUTTON`でボタン種別、disabled、理由コード、中央の到達可能性を記録。
`POINTER`／`CLICK`で入力受信、`HANDLER`でガード通過後の処理開始、`GUARD`で処理拒否理由を記録。
通常はSTART／PAUSE／STOP、計算はSTART／RESUME／STOP／SAVEを対象とする。
sourceはstudyまたはcalculation_1〜7等の固定コードで、課題名や課題IDは記録しない。

状態コードはidle、running、paused、stopping、review_pending、saving、saved、failed、retryable。
初期観測と変化時のみ記録し、許可表から外れた遷移を`INVALID_TRANSITION`にする。
停止処理中のような短い状態もhandler内で記録する。

## 5. disabled理由の検出

既存disabled式を変更せず、同じstateから理由コードを求める。
`button.matches(':disabled')`で親fieldsetによる無効化も検出する。
初回表示／状態変化時に記録するため、disabledボタンへのクリックは不要。

| コード | 対象状態 |
| --- | --- |
| OTHER_TIMER | 他のタイマーが計測中／計算中の通常fieldset |
| UNSAVED_TIME | 対象計算課題に通常学習の未保存時間がある |
| SAVING | 保存中 |
| SAVE_PENDING | 通常学習STOPの保存が再送待ち |
| ZERO_TIME | 保存可能な学習時間が0秒 |
| BUSY／WRONG_PHASE | 連打ガード／handlerが処理可能なphaseではない |

`getBoundingClientRect`、表示・pointer-events、`elementFromPoint`で中央のhit targetを観測。
スクロール、resize、DOM／アニメーション終了でも再評価する。
到達不可だけでは、画面外・重なり・非表示のどれが原因かは断定できない。

## 6. 保存失敗の診断

SAVE_START／SAVE_SUCCESS／SAVE_FAILURE、正規化したコード、再試行可能性、通信状態を記録。
Firebase例外は許可リストにあるcodeだけを採用し、未知の例外はUNKNOWNにする。
message／stack／APIレスポンス全文は診断に保存しない。
既存の時間、得点、STOP時刻、operationの保持とtransaction再試行を維持する。
通常学習と計算の再送待ちをsource別に保持し、一方の成功で他方の失敗を消さない。

## 7. 既存診断との統合

`device-test.ts`と`?deviceTest=1`、既存DeviceTestPanelを再利用。
従来の課題／セッションID・自由文を含む診断キャッシュは診断キーだけを削除する。
ゲーム・学習キャッシュは削除しない。パネルのID／自由文表示を安全なコード表示へ置き換える。

通常利用でも最大50イベントを記録。24時間以上のイベント、未来時刻、不正形式を除外。
このタブのsessionStorageを使用し、reloadで同じ認証セッションの履歴を復元する。
環境（origin／Firebase project／family）とUID／lastSignInTimeを、タブ内乱数でsaltした
SHA-256 scopeへ変換する。入力値はメモリ内だけで使用し、保存もコピーもしない。
scope／saltはコピー対象外。UID変更・再ログイン・環境変更では履歴を分離し、古い非同期応答も除外する。

storage容量不足／Private Mode／crypto利用不能では、そのセッションのメモリ内記録へ退避する。
不正／過大な保存値を読まない（32KB上限）。診断の例外やパネルlistenerの例外は学習へ伝播しない。
Firebaseや外部サービスへ診断を自動送信する処理は追加していない。

## 15. 実端末での利用手順

1. 公開後、Versionがv1.86.3であることを確認し、通常利用で問題を再現する。
2. 問題が起きた**同じタブ・同じログイン状態**でURLに`?deviceTest=1`を付ける。
   既にqueryがあれば`&deviceTest=1`を付ける。サインアウトや新しいタブへの移動は避ける。
3. 必要ならパネルを閉じて操作を確認し、「端末診断」で再び開く。
4. 「安全な診断情報をコピー」を押す。clipboardが使えなければ表示されたtext欄を選択して手動コピー。
5. 保存機能自体が使えないPrivate Mode等では、最初からdeviceTest=1を開き、そのタブ内で操作してコピーする。
