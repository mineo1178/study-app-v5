# v1.89.7 計画の参照保存を独立

正式JSONの選択後に参照プレビューをすぐ表示し、教材の照合・予定採用とは別に「未採用の計画を参照保存」できるようにした。保存後はガントへ移動するボタンを表示する。ファイル選択だけでは本番に書き込まない。

- 入力ファイルの採用フラグは参照保存に使わず、既存の採用済み項目・手動日付・固定目標は従来の変換処理で保持する。
- 参照保存状態、元ファイルrevisionとアプリrevision、正式教材提案数と実taskIdの工程案数を分けて表示する。
- 提案工程が表示期間外なら明示し、「提案期間を表示」で元の日付へ移動できる。過去の日程を今日へ書き換えない。
- 日別工程のない終了日候補ファイルは、その旨と正式JSONを使う手順を示す。終了日から架空の棒を生成しない。
- 既存ガントの7/14日、今日線、青い予定・緑の実績、灰色の未採用提案、詳細・照合・採用を維持。Rules・保存スキーマは変更しない。
